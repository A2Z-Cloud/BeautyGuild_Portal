# Beauty Guild Portal V2

This folder will contain the React Portal V2 frontend when implementation begins.

## Scope
- Membership, Insurance and Accreditation public journeys
- Account checkpoint at the end, or earlier for persistent Save & Finish Later
- CRM-backed draft list, save, resume and discard via backend APIs
- Authenticated portal record management
- V1 Beauty Guild branding and styling

## Ownership
Frontend code and client API adapters live here. Backend services, CRM/Creator automation, Stripe payment logic and Catalyst authentication configuration are implemented and deployed separately by the backend owner.

## Status
Scaffold only. No frontend code copied or deployments configured. V1 source remains in the separate `beauty-guild-catalyst` repository. No framework or deployment decisions are silently introduced.
